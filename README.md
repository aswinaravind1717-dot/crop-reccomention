# Smart Crop Recommendation System

A web-based Smart Crop Recommendation System designed to help farmers identify suitable crops based on agricultural and environmental factors. The system uses machine learning to analyse input parameters and generate crop recommendations.

## Features

- Crop recommendations based on soil type and location.
- Considers previous crops for better recommendations.
- Machine learning-based prediction using Random Forest.
- User-friendly web interface.
- Flask-based backend integration.
- Agricultural dataset for crop prediction.

## Tech Stack

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn, Random Forest
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Dataset:** CSV

## Project Objective

The objective of this project is to demonstrate how machine learning can support agricultural decision-making by providing crop suggestions based on relevant farming conditions.

## Project Status

Developed as an academic project to explore machine learning and web application development in agriculture.
